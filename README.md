# Viberun 1: ToDon't

## Prompt

"Read README.md and generate the client side web application."

## README.md

```md

# Todon't

There are a lot more things we should not do, than things we should do. This app fills a void in a very big market with a nearly infinite problem space that might never run out.

# UX

The user experience consists of a flat list, very similar to a todo list, but with "Todon't" as the header. The user can check off items when they are surely not done.

Tasks can be marked as repeat tasks when created, in which case they are unselected at midnight leaving them cleared for the next day.

# Stack

This implementatin uses vanilla JS, CSS, and localStorage for persistence.


```

The nature of the task is functionally very simple, I expect it to be solved very well.

## Experiences

The current Copilot using GPT is very capable of elegant and well made front-end design.

The app also seem to work perfectly well.

Clearly and unsurprisingly, someone else has had the same app idea. I gave very sparse instructions, having an idea in my mind a bit different than the resulting app, but the elegance of the solution, especially the thoroughly-thought-through wording of the text on the page, makes it very clear that this is based on someone elses work, which makes me think I am not really challenging the A.I. here.

Most interestingly I think: it works well to ask A.I. to read a file with instructions. Next up: formal documentation as a basis for app generation.
