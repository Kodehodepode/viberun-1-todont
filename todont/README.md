# Todon't

There are a lot more things we should not do, than things we should do. This app fills a void in a very big market with a nearly infinite problem space that might never run out.

# UX

The user experience consists of a flat list, very similar to a todo list, but with "Todon't" as the header. The user can check off items when they are surely not done.

Tasks can be marked as repeat tasks when created, in which case they are unselected at midnight leaving them cleared for the next day.

# Stack

This implementation uses vanilla JS, CSS, and localStorage for persistence.
